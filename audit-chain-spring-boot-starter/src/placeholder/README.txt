audit-chain-spring-boot-starter has no source code of its own. It is a dependency
aggregator: adding it brings in the auto-configuration and, through that, the core.

Sources and API documentation live in the artifacts that hold the code:
  io.github.mustafakemalv:audit-chain-core
  io.github.mustafakemalv:audit-chain-spring-boot-autoconfigure
